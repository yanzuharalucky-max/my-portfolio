SYSTEM ARCHITECTURE // FULL-STACK SPECIFICATION

Arsitektur Sistem & Alur Data — Platform Lelang Digital

🏢 Enterprise Monolith Architecture ⚡ Laravel MVC + MariaDB 💳 Midtrans Automated Webhook

Sistem dirancang dengan arsitektur Model-View-Controller (MVC) terstruktur, menerapkan middleware Role-Based Access Control (RBAC) berlapis untuk menjamin isolasi hak akses (Admin, Vendor, Buyer), serta integrasi payment gateway asinkron dengan verifikasi data otomatis.

⚡
< 250ms Response Latency

Optimasi query MySQL berindeks & caching query ringan.

🔒
Multi-Tier RBAC Access Control

Isolasi rute dan otorisasi independen Admin, Vendor, Buyer.

🧪
100% Valid Black Box Testing

Semua 8 skenario pengujian fungsionalitas 100% valid.

🔄
Real-Time Sync Webhook Verification

Validasi signature SHA-512 & auto-settlement instan.

PIPELINE 01

Alur Pemrosesan Request & Keamanan RBAC (MVC Flow)

Bagaimana permintaan pengguna diproses dari peramban hingga tersimpan aman pada basis data relasional:

01 🌐
Client Browser

Klien berinteraksi melalui browser (penawaran lelang, registrasi, deposit). Setiap request dilindungi token CSRF.

HTML5 / Fetch API
02 ⚡
Laravel Routing & Request

Dispatching rute HTTP, sanitasi input form data, dan penegakan limitasi frekuensi request (rate limiting).

Route & FormRequest
03 🛡️
RBAC Security Middleware

Verifikasi sesi login & otorisasi peran (Role-Based Access): Admin (approval), Vendor (katalog), Buyer (bid).

Auth & RBAC Guard
04 🧠
Controller & Logic

Eksekusi aturan lelang: validasi kelipatan harga, pengecekan waktu countdown, dan kalkulasi pemenang bid.

MVC Business Logic
05 🗄️
MariaDB Database

Penyimpanan relasional ACID terindeks: Users, Bids, Auctions, Deposits, dan audit log transaksi aman.

MariaDB 10.x / InnoDB
PIPELINE 02

Alur Pembayaran Otomatis & Webhook Callback (Midtrans)

Integrasi sistem pembayaran asinkron multi-channel dengan verifikasi otomatis server-ke-server:

01 🛒
Client Checkout

User memilih deposit saldo / langganan paket. Backend merequest Snap Token transaksi ke server Midtrans.

Snap.js / Client UI
02 💳
Midtrans Payment Gateway

User menyelesaikan pembayaran via QRIS, Virtual Account (BCA/BNI/Mandiri/BRI), atau E-Wallet terenkripsi.

Midtrans Core API
03 🔄
Webhook / IPN Callback

Midtrans mengirimkan HTTP POST notifikasi asinkron ke server backend. Sistem memvalidasi Signature Key SHA-512.

HMAC SHA-512 Auth
04 ⚡
Verifikasi & Auto-Update

Database transaction berjalan otomatis: status pembayaran diubah ke Settlement, saldo bertambah, akses aktif.

Auto State Settlement
Laravel MVC MariaDB Midtrans Snap RBAC Security Black Box 100%
